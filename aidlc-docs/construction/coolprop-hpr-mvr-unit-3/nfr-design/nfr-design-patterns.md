# Unit 3 NFR Design Patterns

1. Fail-fast finite bounded compression request.
2. Contextual exception translation with causal chaining.
3. Closed named-fallback enumeration.
4. Immutable detached fallback evidence.
5. Build-then-return atomic stream result.
6. Endpoint-preserving reduced-profile fallback.
7. Deterministic example/property matrix.
8. Source/notebook/package/wheel parity gate.

Distributed resilience, scaling infrastructure, security services, and
persistence are not applicable.
