# Unit 3 NFR Requirements

| ID | Requirement |
|---|---|
| U3-NFR-01 | Direct-MVR public error summaries are single-line and at most 512 characters. |
| U3-NFR-02 | Fallback evidence contains primitives only and is deep-copy safe. |
| U3-NFR-03 | Bound rejection performs zero compression-stage property calls. |
| U3-NFR-04 | Required-state failure is atomic for a stream solve. |
| U3-NFR-05 | Existing successful numerical results remain within current tolerances. |
| U3-NFR-06 | Unexpected exceptions are never silently converted into a fallback. |
| U3-NFR-07 | Fixed-seed properties cover boundaries, context, atomicity, and closed codes. |
| U3-NFR-08 | Notebooks execute without treating arbitrary service defects as feasibility. |
| U3-NFR-09 | Focused and integrated tests are deterministic; timing observations are non-flaky evidence. |
| U3-NFR-10 | Source and installed-wheel API behavior agree. |
| U3-NFR-11 | Ruff, formatting, compilation, docs, packaging, and archive checks pass. |
| U3-NFR-12 | No runtime dependency, database, service, or infrastructure is added. |
