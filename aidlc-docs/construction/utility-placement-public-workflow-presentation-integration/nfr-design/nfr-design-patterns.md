# Unit 3 NFR Design Patterns

1. Normalize-before-execute rejects invalid input without side effects.
2. Copy-execute-extract delegates base targeting to isolated problems.
3. Detached-result cache stores immutable output separately from legacy targets.
4. Shared-vector all-period delegation prevents accidental independent solves.
5. Ordered failure-isolating batch reuses `CaseBatchResult`.
6. Result-only presentation prevents hidden numerical work.
7. Generated-artifact ownership keeps the notebook reproducible and drift-checked.
8. Manifest plus source/wheel checks guarantee installed availability.
9. Specialist import containment protects the root facade.
10. Fixed-seed property and end-to-end tests provide repeatability evidence.

Retries, circuit breakers, queues, distributed caches, authentication, and
deployment patterns are N/A because this is a local in-process library surface.
