# Unit 3 Business Rules

1. The public method is keyword-only and requires at least two isothermal levels.
2. Input normalization completes before any existing target service executes.
3. Automatic scope resolves deterministically to direct integration.
4. A placement uses one coordinate vector for every selected period.
5. Public all-period placement delegates once to the primary shared-placement path.
6. Context extraction runs only against isolated problem copies.
7. Physical bounds cover every blueprint coordinate exactly once per period.
8. Generated hot bounds remain above the hottest shifted target interval; generated cold bounds remain below the coldest interval and above absolute zero.
9. Process entropy slices use real temperatures and non-negative interval duties.
10. The source problem retains only a detached placement result; legacy `TargetOutput` remains unchanged.
11. Workspace batch failures are captured per case and never cancel later cases.
12. Reporting consumes supplied or cached placement results and performs no analysis.
13. Root exports remain unchanged; specialist contracts and services remain specialist imports.
14. No CLI method, command, documentation, or test is added.
15. Exactly one generated notebook demonstrates both requested objective workflows.
