# Residual utility design

TargetInput.residual_basis is optional HPRResidualSnapshot. HPRResidualData owns the frozen numerical data. ResidualUtilityTarget distinguishes residual utility allocation in summaries. Application creates detached cases and validates handles. Analysis allocates utilities. Physical slices retain hot/cold side, physical inlet/outlet temperature and duty. PBT-01 compliant; PBT implementation in regression/property tests. Security and Resiliency disabled.
