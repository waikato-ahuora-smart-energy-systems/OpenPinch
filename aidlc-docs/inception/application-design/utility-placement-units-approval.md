# Utility Placement Units Approval

The approved decomposition decisions produced three dependency-ordered units:

1. Placement Contracts and Pure Model
2. Placement Evaluation and Optimisation Service
3. Public Workflow and Presentation Integration

All units ship in the existing OpenPinch package. Thermodynamic and monetary
objectives share one placement pipeline with separate pure evaluators. The
dependency order is acyclic, and every story, FR, NFR, acceptance requirement,
TDD obligation, and enabled PBT rule has an implementation or verification
owner.
