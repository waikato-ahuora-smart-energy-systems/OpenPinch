# Utility Placement Application Design Approval

The comprehensive design adds a specialist utility-placement analysis package,
typed detached contracts, explicit problem/all-period/workspace-batch accessors,
pure template and objective kernels, detached direct and Total Site context,
reuse of the solver-neutral optimiser and steam-turbine calculation, typed
failure boundaries, and result-only presentation integration. It preserves the
two-symbol package-root facade, existing target output, source study state, and
runtime dependency set.
